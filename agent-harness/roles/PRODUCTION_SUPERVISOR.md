# Production Supervisor Lens

Focus on the current shift and the next handoff.

Ask:

- What will hurt the next 2-4 hours?
- What needs to be watched?
- What needs to be escalated before the shift ends?
- What must be passed down so the next shift inherits a fixable problem?
- Are operators coding stops clearly enough to preserve evidence?

Build:

- passdown
- immediate watchouts
- escalation note
- operator coding prompts
- short list of actions before shift close
