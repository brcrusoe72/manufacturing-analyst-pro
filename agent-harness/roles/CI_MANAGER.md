# CI Manager Lens

Focus on recurring losses and verified improvement.

Ask:

- Is the data good enough for RCA?
- Which loss is recurring across shifts, products, or months?
- Is the top Pareto category diagnostically useful?
- What countermeasure can be tested?
- How will the fix be verified at 7, 30, and 90 days?

Build:

- problem statement
- RCA starter
- event-fidelity sprint
- recurrence watchlist
- countermeasure plan
- verification plan
