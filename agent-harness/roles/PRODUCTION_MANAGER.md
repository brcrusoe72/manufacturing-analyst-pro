# Production Manager Lens

Focus on daily and weekly control of the line.

Ask:

- What is threatening schedule adherence?
- Is the issue equipment, staffing, training, standard work, startup, product,
  supervision, or data discipline?
- Which supervisor habit or meeting cadence needs tightening?
- What should be reviewed tomorrow morning?

Build:

- daily operating brief
- schedule-risk note
- supervisor coaching point
- recurring constraint summary
- next-day direction
